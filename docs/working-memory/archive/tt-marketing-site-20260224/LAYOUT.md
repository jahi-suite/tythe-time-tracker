# L — Layout & Look

## Palette
- **Deep green:** #1e3a2a (barn, forest, primary)
- **Muted green:** #2c5530 (secondary, accents)
- **Warm tan:** #c4a574 (wood, grain)
- **Cream:** #faf8f5 (background, soft)
- **Charcoal:** #1a1a1a (text)
- **Warm brown (CTA):** #8b7355
- **Muted text:** #6b7c6d

## Typography
- **Headings:** Fraunces or Playfair Display — elegant, distinctive
- **Body:** Source Sans 3 or DM Sans — clear, readable
- **Pair:** Fraunces + Source Sans 3

## Animations (Framer Motion)
- Fade-in on scroll (once in viewport)
- Stagger children for feature grid
- Subtle scale on hero
- No bouncy, aggressive motion

## Layout
- Mobile-first, 375px baseline
- Generous whitespace
- Sections with clear visual separation
- Max-width container for readability
